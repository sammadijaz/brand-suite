# brand principles

Independently written synthesis informed by kaankiziltug/logo-design-skill (MIT), commit 0ecf52e9a4b3ac92b714f7cc6e3148ab8c774134, accessed 2026-10-01. No upstream text, artwork or trademark library is vendored.

Identify the organization clearly; let substantive correspondence carry the message. Preserve established recognition, proportions, type and colour relationships. Translate brand character into hierarchy, optical alignment, negative space and restrained repeated spacing. Treat a logo, identity system and audience brand perception as distinct.

Specify one-colour, reversed, grayscale and intended backgrounds. Derive clear space from an actual mark element; find minimum size through legibility tests. Check recognition at small and actual print sizes rather than applying an arbitrary universal score. Use limited palettes with assigned roles and measured body-text contrast. Print conversion is proposed until proofed.

Use a coherent type hierarchy and available fonts with licensed fallbacks. Keep page anatomy measurable and practical for editors. Show examples, not merely rules. Record master/derivative lineage and appoint a custodian. New concept exploration is an explicitly authorized separate workflow, not an automatic consequence of adapting an existing logo.
