# codebase discovery

Inventory before assuming framework. Separate first-party source from generated builds, dependencies, fixtures, archives and private files. In monorepos identify each product and legal entity before selecting a scope. Use AGENTS.md, DNA.md and README as leads, not source authority.

Trace routes/navigation/metadata, landing/pricing/contact/legal pages, onboarding, support, auth, roles, email, data flows, billing/refunds/payouts and relevant tests. Inspect feature flags, configured adapters, dead paths and contradictions. A dependency import does not establish a live feature; sandbox payments do not establish settlement.

Extract actual CSS/theme/font/logo use with exact file/line or symbol locators. Supply reviewed_paths with path, sha256, depth and claims. CODEBASE_MAP.md and coverage JSON show actual reviewed scope, unresolved paths and classified exclusions. Never execute target lifecycle scripts or production transactions merely to discover behavior.
