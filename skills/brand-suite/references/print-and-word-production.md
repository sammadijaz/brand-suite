# print and word production

A4 is the reference profile; US Letter is configurable. House defaults: 22 mm side margins, 11 pt body, 9 pt footer, reserved top/bottom zones. These are design choices, not legal standards. Long names/addresses reflow. Word uses native named styles, tables with repeated headings, actual PAGE fields and editable text; no full-page screenshots.

Primary PDFs are exported from the actual generated DOCX using Word COM on Windows or LibreOffice. Chromium prints HTML independently; page counts may differ with font metrics and table flow. Record actual counts rather than forcing a reference total. Disable browser-added headers/footers. Printing digital letterhead on preprinted stock duplicates branding; use a body-only master after explicit selection.

PDF inspection checks searchable ordered semantic content and page boxes and renders every page. Review all Word and HTML page images at readable resolution, including table boundaries, orphan headings and signature continuity. Native Word availability is distinct from a test in every Word version. No PDF/A, PDF/X, accessible tagging, CMYK certification, signing or fillability guarantee is made.
