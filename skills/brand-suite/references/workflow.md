# workflow

Start by choosing a mode and reconciling existing output. Full-suite retains 36 slots; stationery-only and audit-only are partial. Inventory evidence, select one entity, trace relevant first-party claims, assemble typed input, validate, render and inspect every page, then reconcile/package draft outputs. Keep human legal/authority approval separate. New output directories preserve all prior originals. Checkpoint hashes distinguish unchanged reviewed material from stale facts.

The host agent supplies reasoning and reviewed_path entries with exact source hashes, depth and claims. A deterministic script inventories but cannot independently verify company identity, production behavior or law. Ask only for specific missing facts or choices that block the next relevant gate.
