# document catalogue

The machine source is templates/catalogue.json, derived from the user-provided 36-slot inventory. Stable IDs: G00–G02 (3 guides), S01–S07 (7 stationery), P01–P07 (7 people), A01–A08 (8 agreements), C01–C08 (8 governance/institutional), F01–F03 (3 finance). Required formats are HTML, PDF and native DOCX: 108 baseline artifacts for full-suite.

Original drafting clauses and explicit schedules are in templates/documents/clauses.mjs. Canonical models separate facts, proposed terms, review notes, design and instructions, with stable block IDs. A01 is mutual; A02 correctly assigns recipient duties. A07 requires a real processing role/scope schedule. C01/C07 adapt titles and process to actual structure, never a presumed sole member/director.

Every inapplicable slot has a three-format note explaining assessment and replacement needs. Count notes separately from applicable instruments. Unknown facts may permit drafts but block relevant execution. Extra jurisdiction/sector documents receive extra IDs and never replace the 36 baseline slots.
