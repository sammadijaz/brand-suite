# troubleshooting

Run doctor first. Exit 2 means invalid input/schema/flag; 3 missing dependency or unsupported production language; 4 rendering/technical defect; 5 unsafe path/protected master; 6 unresolved execution approval. Error details and preserved controls identify partial progress.

Python dependency missing: create an isolated environment, install requirements.txt and set BRAND_SUITE_PYTHON. Browser missing: select a local Chrome/Chromium with BRAND_SUITE_BROWSER or explicitly install Playwright Chromium in the work area. Browser sandbox failure is not a reason to disable sandbox. Word missing: select a local LibreOffice through BRAND_SUITE_SOFFICE.

Output exists: choose a new version directory. Changed Word or PDF hash: preserve it and review the edits; do not blindly rehash to hide them. No automatic negotiated-DOCX import is claimed. Missing legal/entity fields: continue useful drafts with visible required fields, retain execution blocks. RTL/non-Latin unsupported: choose an appropriately reviewed local renderer/workflow rather than accepting broken glyphs. Complex or raster SVG: request a safe approved source/conversion and keep provenance.

Website inaccessible: local evidence proceeds with explicit limits. Actual Gmail/Outlook/Apple Mail and physical stamp/print proof remain NOT RUN without real tests. Footer text in the middle of a multi-page extracted paragraph is stripped only as a known repeated page zone for semantic checks; substantive content is never removed.
