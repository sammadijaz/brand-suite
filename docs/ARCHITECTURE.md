# architecture

skills/brand-suite is the installed runtime boundary. lib/safety.mjs handles roots, escaping, passive SVG, evidence-independent inventory, public networking constraints and decimal arithmetic. lib/models.mjs validates schemas and assembles semantic blocks from templates/documents/clauses.mjs. lib/render.mjs orchestrates isolated browser output, native Python DOCX and local Word/LibreOffice export. lib/package.mjs creates controls, supplementary email/assets, checkpoints and the manifest.

Python production.py improves native Word handling, font outlines, real PDF inspection and contact sheets. check-package.py is a portable read-only verifier; validate-release.mjs adds externally trusted detached reviewer attestation. No root source folder is required after installation. Plain ESM avoids compiled JavaScript/source mismatch; syntax and schema checks replace an unnecessary TypeScript build.

A semantic model has stable block IDs, explicit categories (fact/proposed-term/review/design/instruction), heading/paragraph/list/table/image/signature/note/page-break blocks, named fields, header/footer, applicability and release state. HTML and DOCX use the same model. Word PDF is primary; browser print is checked independently. Fonts/layout engines can cause page-count differences; counts are measured.

No database, persistent server, mandatory Docker, paid API, proprietary renderer service or external model key. The coding host supplies reasoning. Website fetching is bounded and public first-party only; inventory never claims semantic understanding.
