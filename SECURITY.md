# Security reporting

Do not post credentials, private business documents or exploitable details publicly. Use this repository's GitHub **Report a vulnerability** option if available. If private reporting is unavailable, contact the verified owner through the profile's supported contact options before disclosing sensitive details. No security email address is asserted.

Supported version: current 0.1.x preview. This skill has no telemetry and does not publish generated company documents. Review installed skills and dependencies. The sandbox, XML/Office/archive limits and network/path denial are practical controls, not certification. Reproductions must use synthetic files and local isolated environments. See docs/PRIVACY.md for threat model and boundaries.
